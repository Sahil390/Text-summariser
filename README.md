# Text Summarizer Web App

[![Live Site](https://img.shields.io/badge/Live-Site-brightgreen)](https://text-summariser-ae95.onrender.com/)

A modern, responsive web application that summarizes text using the Gemini API.

## Live Demo

You can try the live application here: [https://text-summariser-ae95.onrender.com/](https://text-summariser-ae95.onrender.com/)

## Features

- **AI-Powered Summarization:** Utilizes the Gemini API for fast and accurate text summarization.
- **Modern & Responsive UI:** Built with Bootstrap 5, the interface is clean, user-friendly, and works on all devices.
- **Character Counter:** Provides real-time feedback on the input text length.
- **Copy to Clipboard:** Easily copy the generated summary with a single click.
- **Clear Text:** Quickly clear the input area to start fresh.

## Technologies Used

- **Backend:**
  - **Flask:** A lightweight Python web framework.
  - **Gunicorn:** A production-ready WSGI server.
  - **Google Generative AI:** The library for interacting with the Gemini API.

- **Frontend:**
  - **HTML5 & CSS3:** For the structure and styling of the application.
  - **Bootstrap 5:** A modern CSS framework for responsive design.
  - **JavaScript:** For client-side interactivity.

- **Deployment:**
  - **Render:** For continuous deployment and hosting.
  - **Docker:** For containerizing the application.
